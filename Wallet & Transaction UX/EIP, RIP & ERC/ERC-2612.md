# ERC-2612

**Yıl:** 2019
**Kategori:** Token UX / İmzalı Onay

## Özet
ERC-20 için `permit` fonksiyonunu tanımlar. Kullanıcının zincir üstü ayrı bir `approve` işlemi göndermeden, imza ile onay verebilmesini sağlar.

## Neden Önemli
Token UX'ini ciddi biçimde iyileştirir. Ekstra işlem ve ekstra gaz ihtiyacını azaltarak daha akıcı onboarding ve işlem akışları sağlar.

## Bağlantılı EIP'ler
- [[EIP-712]] — permit mesajları typed data olarak imzalanır
- [[EIP-1559]] — gas UX tarafıyla birlikte düşünüldüğünde kullanıcı sürtünmesini azaltır
