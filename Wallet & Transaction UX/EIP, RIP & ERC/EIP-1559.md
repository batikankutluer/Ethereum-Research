# EIP-1559

**Yıl:** 2019
**Kategori:** Gas UX / İşlem Ücretlendirme

## Özet
Base fee + priority fee modelini getirir. Kullanıcının tek bir belirsiz `gasPrice` yerine daha öngörülebilir ücret parametreleriyle işlem göndermesini sağlar.

## Neden Önemli
Wallet'ların ücret tahmini ve işlem onay ekranlarını daha anlaşılır hale getirmesine yardımcı olur. Modern transaction UX'in merkezindedir.
