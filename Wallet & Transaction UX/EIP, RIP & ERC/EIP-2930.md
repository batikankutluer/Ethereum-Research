# EIP-2930

**Yıl:** 2020
**Kategori:** İşlem Biçimi / Access List

## Özet
Access list içeren type 1 transaction formatını tanımlar. İşlemin hangi adres ve storage alanlarına erişeceğini önceden belirtmesini sağlar.

## Neden Önemli
Doğrudan son kullanıcı UX'inin merkezinde olmasa da, wallet'ların gelişmiş işlem türlerini desteklemesi ve ücret davranışını daha doğru yönetmesi açısından önemlidir.
