# EIP-1193

**Yıl:** 2018
**Kategori:** Provider Standardı

## Özet
Ethereum Provider JavaScript API'yi standartlaştırır. Modern cüzdanların tarayıcıya nasıl bağlandığını, `request` metodunu ve `accountsChanged` / `chainChanged` gibi event'leri tanımlar.

## Neden Önemli
Wallet ile dapp arasındaki ortak dili kurar. Günümüzde frontend wallet entegrasyonlarının neredeyse tamamı bu model üzerine inşa edilir.

## Bağlantılı EIP'ler
- [[EIP-1102]] — hesap erişimi modeliyle ilişkilidir
- [[EIP-2255]] — permission RPC'leri bu provider üstünden akar
- [[EIP-6963]] — çoklu provider keşfi için 1193 provider'larını hedefler
- [[EIP-5792]] — modern wallet RPC genişlemeleri bu standardı temel alır
