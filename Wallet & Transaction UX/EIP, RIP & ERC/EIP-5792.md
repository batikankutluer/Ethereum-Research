# EIP-5792

**Yıl:** 2022
**Kategori:** Wallet Call API

## Özet
`wallet_sendCalls`, `wallet_getCallsStatus` ve capability sorguları gibi metodlarla modern wallet call API'sini tanımlar. Tek bir RPC çağrısıyla birden çok onchain çağrının işlenmesini hedefler.

## Neden Önemli
Batch işlem, capability discovery ve yeni transaction formatlarına uyum için güçlü bir adaydır. Özellikle smart account ve modern wallet UX dünyasına daha iyi oturur.

## Bağlantılı EIP'ler
- [[EIP-1193]] — provider genişlemesi gibi düşünülebilir
- [[EIP-1559]] — modern transaction UX bağlamında okunur
- [[ERC-4337]] — AA klasöründeki modern wallet execution dünyasıyla doğal kesişimi vardır
