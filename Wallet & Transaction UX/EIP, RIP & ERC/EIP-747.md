# EIP-747

**Yıl:** 2018
**Kategori:** Wallet RPC / Varlık UX'i

## Özet
`wallet_watchAsset` RPC metodunu tanımlar. Uygulamaların cüzdana bir varlığı takip etmesini önermesine izin verir.

## Neden Önemli
Kullanıcının token'ı elle eklemek zorunda kalmamasını sağlar. Özellikle token onboarding UX'i ve cüzdan içi varlık görünürlüğü için önemlidir.

## Bağlantılı EIP'ler
- [[EIP-1193]] — wallet-scoped RPC'ler provider üzerinden kullanılır
- [[EIP-3085]] — benzer biçimde wallet tarafında kullanıcı onaylı UX akışıdır
