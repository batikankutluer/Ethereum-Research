# EIP-1102

**Yıl:** 2018
**Kategori:** Wallet Bağlantı UX'i

## Özet
Hesapların kullanıcı onayı olmadan uygulamaya otomatik verilmemesi fikrini standartlaştırır. `eth_requestAccounts` modeli ile modern connect wallet akışının başlangıcını temsil eder.

## Neden Önemli
Bugünkü "Connect Wallet" deneyiminin güvenlik ve gizlilik temeli budur. Dapp'in kullanıcı hesabını ancak izin sonrası görmesini sağlar.

## Bağlantılı EIP'ler
- [[EIP-1193]] — provider API içinde bu izin modeli yerleşir
- [[EIP-2255]] — daha genel permission sistemine doğru genişler
